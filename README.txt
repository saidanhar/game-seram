MALAM TERAKHIR — GAME HOROR WEB
================================

CARA MENJALANKAN DI WINDOWS + VS CODE
1. Ekstrak file ZIP ini ke folder yang mudah ditemukan, misalnya:
   D:\game-horor\malam_terakhir
2. Buka VS Code.
3. Pilih File > Open Folder.
4. Pilih folder malam_terakhir yang berisi index.html, style.css, game.js.
5. Cara termudah: pasang ekstensi Live Server dari panel Extensions di VS Code.
6. Klik kanan index.html > Open with Live Server.
7. Game akan terbuka di browser.

KONTROL
- WASD atau tombol panah: bergerak
- E: mengambil kunci / mencoba pintu
- M: mematikan atau menyalakan suara
- Cari 3 kunci, lalu menuju pintu KELUAR.
- Setelah mengambil kunci pertama, makhluk akan mulai mengejar.

CARA MENGUBAH GAME
- Teks menu dan judul: index.html
- Warna dan tampilan: style.css
- Logika game, peta, kecepatan, kunci, dan monster: game.js

CARA MENGUNGGAH KE ITCH.IO
1. Uji game terlebih dahulu di browser.
2. Pastikan index.html berada langsung di dalam folder proyek, bukan di folder tambahan.
3. Pilih semua file game yang diperlukan (index.html, style.css, game.js), lalu kompres menjadi ZIP.
4. Buat akun di https://itch.io/ jika belum punya.
5. Buka https://itch.io/game/new
6. Isi judul, deskripsi, jenis proyek HTML, dan informasi lain yang diminta.
7. Pada bagian upload, unggah ZIP game.
8. Untuk game HTML/browser, aktifkan opsi yang menyatakan file ini dapat dimainkan di browser / dimainkan di itch.io.
9. Simpan sebagai draft dan gunakan preview untuk mengetes. Jika sudah benar, publikasikan.
10. Ikuti petunjuk terbaru di itch.io; tampilan dan persyaratan halaman upload dapat berubah.

CATATAN
- Ini adalah proyek awal yang bisa kamu modifikasi. Uji game di beberapa ukuran layar.
- Font online opsional; jika tidak ada internet, game tetap berjalan dengan font cadangan.
- Sebelum publikasi, tulis deskripsi dan kredit untuk aset yang kamu tambahkan. Jangan gunakan gambar, musik, atau suara milik orang lain tanpa izin/lisensi yang sesuai.
- Mengunggah game tidak otomatis menghasilkan uang. Kamu bisa mengatur harga atau pembayaran sukarela sesuai opsi yang tersedia dan kebijakan itch.io.
